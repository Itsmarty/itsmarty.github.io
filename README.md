# martinlouis.info

Source for Martin Louis's professional portfolio, published through GitHub Pages at [martinlouis.info](https://martinlouis.info/).

## Local preview

Serve the repository root with any static file server. For example:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Site structure

- `index.html` contains the complete responsive site.
- `martin-louis.webp` is the optimized profile image.
- `martin-louis-enterprise-ai.png` is the social-sharing image.
- `Martin-Louis-Resume.pdf` is the downloadable résumé.
- `favicon.svg`, `robots.txt`, and `sitemap.xml` support browser and search discovery.

Before publishing, verify factual claims against current source records and check every external link.
